# 来源与编辑政策

## 收录标准

每项事件必须满足以下条件：

1. 由官方机构公布，或由可通过 HTTPS 访问的一手来源记录。
2. `sourceUrl` 直接指向相关公告或原始页面。
3. `description` 只总结来源明确陈述的事实，不加入推测。
4. `verifiedAt` 记录最近一次核验日期。

适合的来源包括政府机构、监管机构、交易所、上市公司、活动主办方和公告原始发布者。二手新闻、聚合器、社交媒体、搜索摘要和复制日历只能帮助定位来源，不能作为最终证据。

## 明确排除

- 传闻和未证实消息。
- 从历史规律推断的日期。
- 预测、目标价、收益预期或无来源估计。
- 只有二手报道支持的记录。
- 证券排名、买卖建议或宣传性文案。

## 更正与状态变更

如果官方来源显示事件延期或取消，请更新 `status`、日期或描述，并保留足够证据解释变化。不要因为事件不再发生而直接删除 `postponed` 或 `cancelled` 记录。

官方页面可能在 `verifiedAt` 之后更新。使用者应在研究前重新打开来源链接，并把日历视为证据索引，而不是不可变事实数据库。

## English

### Inclusion Standard

Every event must be announced by an official body or documented by a primary HTTPS source. The `sourceUrl` must point directly to the relevant announcement, the description must summarize only stated facts, and `verifiedAt` must record the latest review date.

Suitable sources include government agencies, regulators, exchanges, listed companies, event organizers, and original announcement publishers. Secondary news, aggregators, social posts, search snippets, and copied calendars may help locate a source but are not sufficient evidence.

### Exclusions

- Rumors and unverified reports.
- Dates inferred from historical patterns.
- Predictions, price targets, earnings expectations, or unsourced estimates.
- Records supported only by secondary reporting.
- Security rankings, trading advice, or promotional copy.

### Corrections And Status Changes

When a primary source shows that an event was postponed or cancelled, update `status`, dates, or description and preserve enough evidence to explain the change. Do not delete a record only because the event will no longer occur.

Official pages can change after `verifiedAt`. Re-open the source before research and treat this calendar as an evidence index, not an immutable facts database.
